Este repositório contém os arquivos SQL desenvolvidos para o projeto final da disciplina de Banco de Dados.

📁 Arquivos incluídos
✔ 01_create_tables.sql

Criação de todas as tabelas do banco SkillGrowth.

✔ 02_insert_select.sql

Inserção de dados e consultas (SELECT) com JOIN, WHERE, LIMIT e ORDER BY.

✔ 03_update_delete.sql

Scripts de atualização (UPDATE) e exclusão (DELETE).
